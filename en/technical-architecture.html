The five layers

From interface to infrastructure.

Interface

Web dashboards, chat and REST APIs to integrate AI functions into the tools the team uses every day.

Application

Containerised microservices orchestrating models, business rules and workflows.

Models

Language models, computer vision and language processing, hosted on-premise or in a private cloud.

Data

Relational and vector databases, message queues and pipelines for structured and unstructured data.

Infrastructure

On-premise servers, European private cloud or hybrid architectures, with infrastructure as code.

Integrations

MCP connectors to ERP, CRM and document archives.

Technology stack

Open, replaceable components, no vendor lock-in.

Models and orchestration

Data and application

Frequently asked questions

Do the solutions work without the cloud?

Yes. Models, data and application can run entirely on servers in the company. The European private cloud is an option, not a requirement.

Can I switch language model later?

Yes. The architecture separates models from the application: you can move from an open model to a commercial one, or vice versa, without rewriting the integrations.

How are updates managed?

With controlled, repeatable releases (infrastructure as code), automated tests and the ability to roll back to the previous version.
